# sysmon-widget v0.2.1 · 2026-11-16

首个公开发布版本。Windows 桌面监控贴片：本机 + `~/.ssh/config` 中的 Linux 主机，CPU / 内存 / NVIDIA GPU 占用与 Top10 进程。

## 中文

### 主要变化

- **主机列表自动同步 `~/.ssh/config`**：启动、重载配置、手动「同步 SSH 别名」时，把缺失的 `Host` 别名自动加入（排除 `*` `?` `!` 通配项）；已有主机保留自定义显示名与启用/停用状态，只增不删，同步幂等。
- **贴片直接看多机**：tile 扩大到 420×280，底部主机条一行显示 `本机 + 全部远程` 的 `CPU%/GPU%` 与在线状态点；点 chip 切换、双击进入该主机详情。
- **可读性优化**：统一字号阶梯（环形数字 26px、标签 14px、数值 13px、chips 12px），次要文字提升到 `#aeb9c6`、标签 `#c8d3e0`、主数值 `#f0f6fc`；面板 alpha 0.90，亮色壁纸上仍清晰。
- **多 GPU**：detail 中每块 GPU 一张卡片（利用率 / 显存 / 温度，可滚动），曲线取 GPU #0 并在图例标注。
- **桌面集成**：单实例（重复启动唤起已有窗口）、开机自启（HKCU Run，无需管理员）、不透明度滑块、托盘「重新加载配置」与 `本机 CPU · 内存 · 在线 n/m` tooltip。
- **远程采集**：每台主机一次 SSH 往返、8 秒超时、失败指数退避、每主机独立线程；进程 CPU% 为 `top -bn2` 第二段的瞬时值（多核可 >100%）。

### 修复

- 无 NVIDIA GPU 的主机不再常驻黄色错误条（`nvidia-smi` 缺失或 `No devices found` 时静默回退）。
- 窗口隐藏时不再推送采集事件，降低空闲开销；重新显示后自动补齐。
- 主机 chips 改为单行 + 横向滚动，不再折行挤压 sparkline。
- 关闭窗口只隐藏到托盘，不退出进程。

### 验证

- `cargo test`：26 个单元测试通过（nvidia-smi 解析、远程输出解析、`/proc/stat` 双采样、ssh config 别名同步、配置兼容、托盘摘要、尺寸断言等）。
- `npm run build` + `npm run tauri build` 通过，release exe 约 4.9 MiB，常驻内存约 36 MB。
- 真实环境实测：256 核 + RTX 4090 主机（tile/grid/detail 在线数据）、20 核 + RTX 3090 主机、仅密码认证主机正确显示离线原因。

### 安装

下载 `sysmon-widget_0.2.1_x64-setup.exe`（NSIS，推荐）或 `sysmon-widget_0.2.1_x64_en-US.msi`。

要求：Windows 10/11 x64 + WebView2；远程主机需 Linux/POSIX、密钥免密 SSH；GPU 指标可选，需要 NVIDIA + `nvidia-smi`。

### 已知限制

- 远程仅支持 Linux/POSIX，不支持密码/键盘交互认证。
- GPU 仅支持 NVIDIA；历史数据只在内存（默认 180 点 ≈ 6 分钟），无告警与持久化。
- 界面目前为中文文案（英文 README 已提供）。

## English

First public release. A Windows desktop widget for monitoring your local machine plus Linux hosts from `~/.ssh/config`: CPU, memory, NVIDIA GPU usage and Top-10 processes.

### Highlights

- **Host list auto-syncs from `~/.ssh/config`**: missing `Host` aliases are appended on startup, config reload, or the manual *Sync SSH aliases* action (wildcards `*` `?` `!` ignored). Existing entries keep their custom label and enabled state — append-only and idempotent.
- **All hosts on the tile**: the tile grows to 420×280 and shows `local + every remote` in a single host strip with `CPU%/GPU%` and an online dot. Click to switch, double-click to open that host's detail.
- **Readability pass**: unified type scale (26 px ring values, 14 px labels, 13 px values, 12 px chips), brighter secondary text (`#aeb9c6`), labels `#c8d3e0`, values `#f0f6fc`; panel alpha 0.90 stays legible on bright wallpapers.
- **Multi-GPU**: one card per GPU in detail (utilization / VRAM / temperature, scrollable); charts follow GPU #0 and say so in the legend.
- **Desktop integration**: single instance (second launch focuses the existing window), launch at login (HKCU `Run`, no admin rights), opacity slider, tray *Reload config*, and a `local CPU · memory · online n/m` tooltip.
- **Remote collection**: one SSH round trip per host, 8-second timeout, exponential backoff, one thread per host. Process CPU is the instantaneous value from the second `top -bn2` sample (can exceed 100% on multi-core).

### Fixes

- Hosts without an NVIDIA GPU no longer show a permanent yellow error strip (`nvidia-smi` missing or `No devices found` now degrades silently).
- No event emission while the window is hidden; the UI catches up when shown again.
- Host chips stay on one line with horizontal scrolling instead of wrapping over the sparkline.
- Closing the window hides to tray instead of exiting.

### Verification

- `cargo test`: 26 unit tests passing (nvidia-smi parsing, remote record parsing, `/proc/stat` double sampling, ssh alias sync, config compatibility, tray summary, size assertions).
- `npm run build` and `npm run tauri build` succeed; release exe ≈ 4.9 MiB, ~36 MB RSS.
- Tested against real hosts: 256-core + RTX 4090 (live tile/grid/detail data), 20-core + RTX 3090, and a password-only host that correctly reports itself offline.

### Install

Download `sysmon-widget_0.2.1_x64-setup.exe` (NSIS, recommended) or `sysmon-widget_0.2.1_x64_en-US.msi`.

Requires Windows 10/11 x64 + WebView2. Remote hosts need Linux/POSIX and key-based SSH. GPU metrics are optional (NVIDIA + `nvidia-smi`).

### Known limitations

- Remote hosts must be Linux/POSIX; password / keyboard-interactive auth is not supported.
- NVIDIA-only GPU support; history is in-memory (180 points ≈ 6 minutes), no alerting or persistence.
- UI copy is currently Chinese; documentation is bilingual.
